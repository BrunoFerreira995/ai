# Phase 9 — Hyperparameter Optimization

This module supports:

- Learning-rate search
- Batch-size tuning
- Optimizer comparison
- Dropout and regularization tuning
- Reproducible random search
- Bayesian optimization through Keras Tuner

Run the tests:

```bash
TF_CPP_MIN_LOG_LEVEL=2 .venv/bin/python -m unittest discover -s phase9_hyperparameter_optimization -p 'test_*.py'
```
