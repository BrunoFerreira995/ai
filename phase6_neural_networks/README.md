# Phase 6 — Neural Networks

Keras implementations covering:

- Dense layers, activation functions, batch normalization, and dropout
- CNNs with `Conv2D`, pooling, and residual blocks
- EfficientNet, MobileNet, and ResNet backbones without downloading weights
- LSTM, GRU, and encoder-decoder Seq2Seq models
- Transformer positional encoding, multi-head attention, encoder block, and classifier

Run the tests from the project root:

```bash
TF_CPP_MIN_LOG_LEVEL=2 .venv/bin/python -m unittest discover -s phase6_neural_networks -p 'test_*.py'
```
