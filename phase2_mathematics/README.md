# Phase 2 — Mathematics

This module contains executable foundations for the mathematics used in the
TensorFlow roadmap.

## Covered topics

- Linear algebra: scalars, vectors, matrices, tensors, matrix multiplication,
  eigenvectors, and eigenvalues.
- Calculus: derivatives, partial derivatives, gradients, the chain rule,
  Jacobians, and Hessians.
- Probability: Bayes' theorem, Gaussian density, Bernoulli mass, softmax, and
  categorical cross-entropy.

Run the tests from the project root with:

```bash
.venv/bin/python -m unittest discover -s phase2_mathematics -p 'test_*.py'
```
