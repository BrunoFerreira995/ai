# Phase 4 — Data Engineering

Reusable tabular-data utilities for the roadmap:

- Cleaning missing values and duplicates
- IQR outlier detection and removal
- Label validation
- Min-max normalization and z-score standardization
- One-hot encoding
- Variance-based feature selection
- Stratified train/validation/test splitting

Run the tests from the project root:

```bash
.venv/bin/python -m unittest discover -s phase4_data_engineering -p 'test_*.py'
```
